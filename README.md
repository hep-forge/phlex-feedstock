Feedstock for [phlex](https://github.com/Framework-R-D/phlex) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

Parallel, Hierarchical, and Layered Execution of data-processing algorithms

## Architectures

State per architecture: see the platforms badge above or [anaconda.org/hep-forge/phlex](https://anaconda.org/hep-forge/phlex).


## Install

```bash
conda install -c hep-forge -c conda-forge phlex
```
